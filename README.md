# מתרגם כתוביות — PWA עם תמיכה בשיתוף מוואטסאפ

כלי client-side לחילוץ שמע מווידאו, תרגום עם Gemini, ויצירת כתוביות — הכל בדפדפן.
המפתח והקבצים לא יוצאים מהמכשיר (חוץ מהשמע שנשלח ל‑Google עם המפתח שלך).

## מה חדש בגרסה הזו
- ניתן **לשתף סרטון ישירות מוואטסאפ** אל האפליקציה (אנדרואיד).
- מותקנת כאפליקציה (PWA) עם אייקון במסך הבית.
- זוכרת את מפתח ה‑API במכשיר (אופציונלי).

## פריסה (חינם, בלי שרת)

צריך HTTPS כדי ש‑PWA ו‑Share Target יעבדו — קובץ מקומי לא יספיק. הכי מהיר:

### אפשרות א' — Netlify Drop (הכי קל)
1. היכנסו ל‑app.netlify.com/drop
2. גררו את **כל התיקייה הזו** לחלון.
3. קיבלתם כתובת HTTPS. זהו.

### אפשרות ב' — GitHub Pages
1. צרו repo והעלו את הקבצים.
2. Settings → Pages → Branch: main → Save.
3. הכתובת תהיה `https://USER.github.io/REPO/`.

> הערה ל‑GitHub Pages: כל הנתיבים כאן יחסיים, אז זה עובד גם תחת תת-נתיב `/REPO/`.

## התקנה בטלפון (אנדרואיד)
1. פתחו את הכתובת ב‑Chrome.
2. תפריט ⋮ → **התקן אפליקציה / הוסף למסך הבית**.
3. פתחו פעם אחת, הזינו מפתח Gemini וסמנו "זכור".

## שימוש דרך וואטסאפ (אפס לחיצות מיותרות)
לאחר הגדרה חד-פעמית (מפתח שמור), הזרימה היא:
1. בוואטסאפ: סרטון → **שתף** → **מתרגם כתוביות**.
2. זהו. האפליקציה נפתחת, מחלצת שמע, מתרגמת, ו**מנגנת אוטומטית עם הכתוביות**.

ההגדרות (מפתח, שפה, מודל) נשמרות ומתקפלות אחרי הפעם הראשונה, כך שהמסך פתוח ישר לפעולה.
גם בבחירת קובץ ידנית — ברגע שבוחרים קובץ, התרגום מתחיל לבד (אם יש מפתח שמור).

### סטטוסים בוואטסאפ
לסטטוסים אין "שתף לאפליקציה". הדרך: בזמן צפייה בסטטוס — לחיצה ארוכה → **Forward** → שלחו לעצמכם.
הסטטוס הופך לסרטון רגיל בצ'אט, ומשם שתפו לכלי כרגיל.

## עיצוב כתוביות והורדת וידאו מתורגם
לאחר יצירת הכתוביות, בתוך מסך התוצאה:
- **עיצוב ומיקום**: מיקום (תחתית/מרכז/עליון), מרחק מהקצה, גודל גופן, צבע, שקיפות רקע, גופן, מודגש, ומסגרת/צל. הכל משפיע חי על התצוגה ונשמר להמשך.
- **הורדת וידאו עם כתוביות מובנות**: כפתור שצורב את הכתוביות המעוצבות לתוך הווידאו (canvas + הקלטה), כולו במכשיר. הצריבה בזמן אמת — סרטון של 2 דק' לוקח ~2 דק'.

הערה על פורמט: הפלט יהיה mp4 אם הדפדפן תומך בהקלטת mp4, אחרת webm. אם תרצו mp4 תמידי לשיתוף חוזר בוואטסאפ — נוסיף שלב המרה.

## מפתח Gemini
חינם ב‑https://aistudio.google.com/apikey — הדביקו בשדה בתוך האפליקציה.

## מגבלות ידועות
- **iOS**: אייפון לא תומך בקבלת שיתופים ל‑PWA. שם: שמרו את הסרטון ואז בחרו אותו ידנית באפליקציה.
- **אורך**: השמע נשלח בקריאה אחת, כך שהתקרה היא בערך 30–40 דקות וידאו. חלוקה לקטעים ארוכים — צעד הבא.
- אבטחה: אם סימנתם "זכור מפתח", הוא נשמר ב‑localStorage במכשיר. אל תשתמשו בזה במכשיר משותף.
