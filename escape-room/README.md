# מחוץ למחנה

חדר בריחה מקוון לשני שחקנים על טהרת המצורע. זהו החדר הראשון, "מחוץ לחומה". התכנון המלא נמצא ב־[DESIGN.md](DESIGN.md).

## מה יש בחדר הראשון

1. **הכהן בלשכת השער.** לומד בספר הנגעים ועובר את מבחן המראות. הדלת נפתחת רק אחרי שעבר.
2. **המצורע בעמק.** מסתובב בין הסוכה, המעיין, השדה עם שעון השמש ודוכן הרוכל. אינו יכול להתקרב לשער.
3. **הבדיקה.** מתקיימת רק כששני השחקנים עומדים יחד בחוץ. המצורע קובע את השעה ליד שעון השמש ואת עמידתו. הכהן בוחן את הנגעים בזכוכית מגדלת ומודד אותם בגריס. התאורה משנה את מראה הנגעים לפי משנה נגעים ב, ב.
4. **השוק והמעיין.** אחרי שהכהן פוסק "טהור" ומצווה, המצורע קונה ציפורים, ארז, שני תולעת, אזוב וכלי, וממלא מים. הכהן בודק את הסל ומאשר את כולו או מחזיר אותו.

## הכרעות הלכתיות

- **מראות הנגעים:** כחכמים וכרמב"ם. שאת כצמר לבן, ותולדתה כקרום ביצה.
- **שעות הראייה:** כרבי יהודה, ארבע, חמש, שמונה ותשע.
- **המקורות:** כל מקור שהמשחק מציג נמצא ב־`src/content.js` עם מראה מקום.
- **לבירור:** הסעיפים המסומנים "לבירור" ב־DESIGN.md עדיין צריכים בדיקה של תלמיד חכם.

## איך משחקים

- **מקוון:** פותחים את הקישור המשותף. שחקן אחד פותח חדר ומקבל קוד בן ארבעה תווים, והשני מצטרף עם הקוד. שני השחקנים צריכים הרשאת עריכה לעמוד.
- **מקומי:** פותחים את `dist/index.html` בשתי לשוניות של אותו דפדפן.
- **שיחה:** מדברים בשיחה קולית לאורך כל המשחק.

## מבנה הקוד

| קובץ | תפקיד |
|---|---|
| `src/content.js` | כל התוכן: מקומות, נגעים, פריטים, דפי הספר ומקורות |
| `src/logic.js` | חוקי המשחק כפונקציות טהורות, בלי ממשק. אותו קובץ ירוץ בעתיד בשרת |
| `src/net.js` | סנכרון בין השחקנים. כרגע מסד הנתונים של הארטיפקט, או לשוניות באותו דפדפן |
| `src/art/` | הפנורמה, הסצנות הקרובות, הטקסטורות והתאורה לפי השעה |
| `src/ui/` | הספר, הבדיקה, השוק והמעיין |

## בנייה

```
npm install
npm run build
```

הבנייה יוצרת את `dist/index.html`, מסמך מלא, ואת `dist/artifact.html`, הגרסה לפרסום.
